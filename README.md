# IPL-Performance-Analysis-Project

An interactive Power BI dashboard that provides a comprehensive analysis of IPL matches from the 2023–2025 seasons. The dashboard combines key match statistics, team performance, venue insights, and forecasting into a single, interactive report to support data-driven sports analysis. 📊🏆

✨ Key Features
📊 KPI Cards — Total Matches, Total Runs, Total Wickets, Average First Innings Score, and Average Second Innings Score.
🏆 Team Performance Analysis — Bar charts showing matches won by each team.
🎯 Toss Analysis — Donut charts displaying toss decisions and their impact on match results.
🏟️ Venue Analysis — Visuals comparing match outcomes across different venues and venue types.
📈 Scoring Trends — Line charts showing first and second innings scoring patterns.
🔮 Forecasting — Power BI Analytics Forecast predicting future scoring trends using historical match data.
🎛️ Interactive Filters — Slicers for Team, Match Stage, Venue Type, Toss Decision, and Season.
🛠️ Tech Stack
💎 Tool: Microsoft Power BI
📁 Data Source: IPL Match Dataset (2023)
📊 Visuals: KPI Cards, Bar Charts, Line Charts, Donut Charts, Pie Charts, Slicers, Forecasting
📐 DAX: Custom Measures and Calculated Columns
💡 Insights Delivered

This dashboard helps users quickly analyze:

🏏 Team-wise performance and match wins
📊 Match scoring trends and average innings scores
🎯 Toss decisions and their impact on winning
🏟️ Venue-wise match performance
📅 Season-wise IPL trends and forecasting of future scores
